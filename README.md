# 🎀 雌小鬼卜卦 · 翻车Flag模拟器

> 64卦卜卦 + Flag打脸监督 —— 一个表面可爱实则阴阳怪气的AstrBot群聊娱乐插件 ✨

## ✨ 功能介绍

| 功能 | 说明 |
|:---|:---|
| 🔮 周易卜卦 | 完整64卦，卦辞解读+时运财运感情合为一句雌小鬼吐槽，配卦象图片 |
| 🏴 Flag监督 | 立Flag自动算卦（凶卦概率可调），立完就问惩罚 |
| ⛏️ 打脸挖坟 | @某人挖出Flag公开处刑，每天次数可调 |
| 📝 自动判定 | 回复"实现了"/"失败了"自动判定，失败附带社死惩罚 |
| 🎪 排行榜 | 打脸名人堂 + 预言家榜单 |
| 💬 卦象彩蛋 | 发言概率触发，64卦专属雌小鬼吐槽 |

## 🚀 安装

AstrBot WebUI 插件市场搜索 `astrbot_plugin_iching_flag` 安装。

或手动克隆到 `data/plugins/` 目录。

## 📖 指令列表

| 指令 | 说明 |
|:---|:---|
| `/卜卦` `/算卦` `/来一卦` | 随机卜一卦（每日1次） |
| `/flag 内容` | 立Flag，自动算卦 |
| `/打脸` `/打脸 @某人` | 挖出Flag公开处刑（每日可调） |
| `实现了` / `失败了` | 回复判定Flag结果 |
| `/flag排行` | 查看失败排行（打脸名人堂） |
| `/flag排行 成功` | 查看成功排行（预言家榜单） |

## ⚙️ 可配置项

在 WebUI 插件设置中调整：

- 彩蛋触发概率
- 每日算卦/打脸次数
- 立Flag凶卦概率
- 惩罚模板自定义

## 🎭 特色：雌小鬼风格

表面可爱贴心，实则阴阳怪气幸灾乐祸。卦象不吉会嘲讽你，Flag倒了公开处刑，成功了还要嘴硬说"哼，算你厉害"。
